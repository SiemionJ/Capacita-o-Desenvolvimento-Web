HTML:

Para o desenvolimento dessa página foram utilizadas diferentes linguagens de programação. Para a primeira semana de capacitação esse site foi estruturado em HTML. Linguagem essa que serve como "esqueleto" da página, estruturado todas as divisões dos site, abrigando os textos, links e imgaens.

    Dentre as TAGS de texto utilizadas nessa etapa temos:
  • h1 à h6: cria um bloco o texto do tipo título, de tamanhos 1 (maior) ao 6 (menor);
  • p : cria um bloco de texto padrão;
  • ul : cria um bloco de texto no formato de lista não-ordenada;
  • ol : cria um bloco de texto no formato de lista ordenada;
  • strong : serve para deixar o texto em negrito;
  • em : serve para deixar o texto em itálico;
    A programação segue a seguinte estrutura:
  1. Cabeçalho: uilizando a tag head, cria a seção que abriga o título do projeto, e demais informações disponibilizadas pelo desenvolvedor;
  2. Corpo: utilizando a tag body, engloba todos os elementos visuais presentes no site;
  3. Container: utilizando a tag div, agrupa os elementos atribuidos a ele em um bloco persnalizável.

Imagens, links e botões também podem ser adicionados à página com HTML, utilizando as tags img,a e button respectivamente.
